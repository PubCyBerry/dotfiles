# Global Agent Configuration

## 언어와 문서
- 답변은 한국어로 작성한다. 기술 용어, 코드, 고유명사는 원어를 유지한다.
- Markdown 문서(README 등)는 한국어로 작성한다.
- 코드 주석은 한국어로 작성한다. 단, 공개 API 명세, 외부 기여 규칙, 기존 파일의 주석 스타일이 영어인 경우에는 그 맥락을 따른다.

## 도구 사용

### 데이터 처리
- JSON은 `jq` 파이프라인으로 처리한다.
- YAML/TOML은 `yq`로 처리한다.

### GitHub
- GitHub 작업은 `gh`를 사용한다.

### CLI 실행
- 외부 CLI는 비대화형 옵션을 우선한다. 예: `--yes`, `--quiet`, `--no-interactive`.
- JSON 출력을 지원하는 CLI는 `--json` 옵션을 우선한다.
- 사용자에게 CLI 명령어를 안내할 때 Windows는 Git Bash, Linux는 Bash 기준으로 작성한다.

## 설명 방식
- 내용이나 개념을 설명할 때 텍스트만 나열하기보다 한눈에 구조가 보이는 형식을 우선한다.
- 관계, 흐름, 단계, 계층, 비교가 있는 내용은 표, 목록, 트리, 다이어그램, Mermaid 중 적합한 형식을 사용한다.
- 단순한 답변은 과하게 시각화하지 않는다. 이해 속도가 빨라지는 경우에만 구조화한다.

## 개발 환경 변경
- 원칙: 호스트 환경을 직접 변경하지 않는다. 프로젝트 로컬, 일회성, 격리된 실행 환경을 우선한다.
- 명시 요청이 없으면 전역 설치를 하지 않는다. 예: `pip install`, `npm install -g`, `gem install`, `cargo install`, `go install`, `brew install`, `apt install`, `winget install`.
- OS 패키지 매니저, 관리자 권한, `sudo`가 필요한 작업은 사용자 요청 또는 명시 승인이 있을 때만 수행한다.
- Python은 `uv run`, `uvx`, `uv sync`, 프로젝트 `.venv`를 우선한다. 활성화된 가상환경이나 프로젝트 로컬 환경이 확인되지 않으면 `pip install`을 사용하지 않는다.
- Node.js는 `packageManager` 필드와 lockfile을 확인하고 프로젝트의 패키지 매니저를 따른다. 일회성 도구는 `npm exec`, `pnpm dlx`, `yarn dlx`, `bunx`를 우선한다.
- 컨테이너로 실행 가능한 작업은 Docker/Dev Container처럼 삭제와 재현이 쉬운 격리 환경을 우선한다.
- 의존성을 추가할 때는 먼저 manifest와 lockfile을 확인한다. 런타임 의존성/개발 의존성 구분을 유지하고 변경 사항을 해당 파일에 반영한다.
- 호스트 설치가 불가피하면 이유, 변경 범위, 되돌리는 방법을 설명하고 사용자 동의를 받은 뒤 진행한다.
- 임시 도구, 캐시, 빌드 산출물은 가능하면 작업 디렉터리 내부나 OS 임시 디렉터리에 두고 작업 후 정리한다.

## 작업 지속성
- 여러 단계가 있거나 파일을 수정하는 작업은 현재 작업 디렉터리의 `CONTEXT.md`를 세션 인계 파일로 사용한다.
- 작업 시작 시 `CONTEXT.md`가 있으면 먼저 읽는다. 없으면 이어받을 상태가 생겼을 때 만든다.
- 기존 `CONTEXT.md`가 도메인 문서, 결정 기록, 글로서리로 쓰이고 있으면 기존 구조를 보존하고 `## 작업 인계` 섹션만 추가하거나 갱신한다.
- 기록은 다음 항목을 중심으로 짧게 유지한다: 목표, 현재 상태, 완료한 일, 남은 일, 변경한 파일, 검증 결과, 결정한 사항, 가정, 블로커, 다음에 실행할 명령.
- 계획 확정, 의미 있는 파일 수정, 테스트/검증 완료, 블로커 발견, 중단 직전처럼 이어받기에 필요한 상태가 바뀔 때 갱신한다.
- 비밀값, 토큰, 개인정보, 긴 로그 전문은 기록하지 않는다. 필요한 경우 위치와 요약만 남긴다.
- 작업 완료 시 완료 상태, 검증 결과, 남은 일이 있는지 여부를 `CONTEXT.md`에 정리한다.
- 단발성 조회나 간단 답변처럼 이어받을 상태가 없는 작업은 생략할 수 있다.

## 웹 검색
- 라이브러리, 패키지, API 버전은 공식 문서를 확인한 뒤 답변한다.
- 가격, 제품 스펙, 서비스 정책은 훈련 데이터를 신뢰하지 않고 검색을 우선한다.
- 순수 코딩 로직, 알고리즘, 리팩터링은 검색 없이 진행한다.
